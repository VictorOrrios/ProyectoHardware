Detailed Description

Hardware abstraction layer for microcontroller peripherals.

Provides a hardware-independent interface for:

  • GPIO management
  • Timer operations
  • UART communication
  • External interrupts
  • Power management
  • Random number generation
  • Watchdog timer
  • Critical sections
