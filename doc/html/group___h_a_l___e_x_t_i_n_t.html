void hal_ext_int_registrar_callback ( void(* callback )(uint32_t))

Register callback function for external interrupts.

Registers a handler that will be called when an external interrupt occurs. The callback receives the pin number that generated the interrupt as a parameter.

Parameters
callbackFunction to call on external interrupt. If NULL, notifications will be disabled.
