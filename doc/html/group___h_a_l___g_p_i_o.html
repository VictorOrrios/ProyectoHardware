◆ hal_gpio_leer_n()

uint32_t hal_gpio_leer_n ( HAL_GPIO_PIN_T gpio_inicial,
uint8_t num_bits )

Read value from multiple GPIO pins.

Returns an integer with the value of the specified bits. Example:

  • Pin values: 0x0F0FAFF0
  • Initial bit: 12, num_bits: 4
  • Return value: 10 (reads bits 12-15)
Parameters
gpio_inicialFirst GPIO pin to read
num_bitsNumber of consecutive pins to read
Returns
uint32_t Value read from pins
