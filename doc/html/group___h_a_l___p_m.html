void hal_consumo_dormir ( void )

Put microcontroller in sleep mode.

Minimum power consumption mode where most peripherals and main clock are stopped. Only essential peripherals configured for wake-up remain active.

◆ hal_consumo_esperar()

void hal_consumo_esperar ( void )

Put microcontroller in wait mode.

In this mode, the processor stops execution but keeps peripherals active. Wakes up on any interrupt. Moderate power consumption.
