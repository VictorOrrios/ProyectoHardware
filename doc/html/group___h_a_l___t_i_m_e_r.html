◆ hal_tiempo_iniciar_tick()

uint32_t hal_tiempo_iniciar_tick ( void )

Initialize and configure system tick counter.

Configures and starts the hardware tick counter and returns the conversion factor hal_ticks2us, which allows converting from hardware ticks to microseconds.

Note
The driver will use this to work with us and ms while converting to hardware ticks internally
Returns
uint32_t Conversion factor from ticks to microseconds
