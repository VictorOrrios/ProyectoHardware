Hardware Project 2024 - Microkernel Documentation

Overview

Welcome to the documentation for the Hardware Project 2024 Microkernel. This real-time microkernel is designed for embedded systems, providing a robust and flexible platform for developing interactive applications.

Key Features

  • Hardware Abstraction Layer (HAL)
    • Support for LPC2105 (ARM7) and NRF52840 (Cortex-M4F)
    • Platform-independent peripheral access
    • Unified interrupt handling
  • Real-Time Event System
    • Event-driven architecture
    • Priority-based scheduling
    • Efficient message queuing
    • Deterministic timing
  • Service Layer
    • Logging system with multiple severity levels
    • Statistics collection and performance monitoring
    • Alarm and timer management
    • Power management services

Getting Started

To begin using the microkernel:

  1. Choose your target platform (LPC2105 or NRF52840)
  2. Configure the HAL for your platform
  3. Initialize required services
  4. Set up your application event handlers

Example initialization code:

int main(void) {
uint32_t num_leds;
uint32_t num_botones;
// Initialize Hardware Abstraction Layer
hal_gpio_iniciar(); // Must be first - other drivers depend on GPIO
hal_ext_int_iniciar(); // External interrupts for buttons
// Initialize Basic Drivers
num_leds = drv_leds_iniciar();
drv_monitor_iniciar();
drv_tiempo_iniciar();
drv_consumo_iniciar(MONITOR4, MONITOR3);
// Initialize Runtime System
rt_FIFO_inicializar(MONITOR4);
rt_GE_iniciar(MONITOR1);
// Initialize Services
num_botones = drv_botones_iniciar(rt_FIFO_encolar,
ev_PULSAR_BOTON,
ev_RETARDO,
ev_DOBLE_BOTON_PULSADO,
DOUBLE_BUTTON_TIMEOUT_MS);
svc_log_iniciar(MONITOR1, rt_FIFO_encolar, ev_UART_FREED);
svc_alarma_iniciar(MONITOR2, rt_FIFO_encolar, ev_T_PERIODICO);
// Launch application (if hardware available)
if (num_leds > 0 && num_botones > 0) {
// Your application code here
}
// Enter event processing loop - never returns
rt_GE_lanzador();
return 0;
}
