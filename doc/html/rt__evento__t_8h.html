Detailed Description

Event Types Definition.

Defines the event types that can be handled by the real-time system. Each event represents a specific action or occurrence that needs to be processed by the system.

Enumeration Type Documentation

◆ EVENTO_T

enum EVENTO_T

Event types supported by the system.

Note
The numeric values are important and must not be modified as they are used as array indices.
Enumerator
ev_VOID 

Null event. Used as default value or to indicate absence of event.

ev_T_PERIODICO 

Periodic timing event. Generated by the alarm system for periodic tasks.

ev_PULSAR_BOTON 

Button press event. Generated when a valid button press is detected.

ev_INACTIVIDAD 

User inactivity event. Generated when no interaction is detected for a defined period.

ev_RETARDO 

Delay event. Used to implement non-blocking delays in the system.

ev_BLINK 

LED blink event. Controls LED blinking timing.

ev_WDT 

Watchdog feed event. Used in watchdog timer implementation.

ev_COUNTER_STRIKE 

Counter Strike game event. Manages game logic for Counter Strike.

ev_TEST 

Generic test event. Can be used by all test modules.

ev_SIMON_GENERICO 

Simon Says game event. Manages game logic for Simon Says.

ev_FEED_WDT 

Watchdog feed event. Similar to ev_WDT, used for watchdog timer reset.

ev_DOBLE_BOTON_PULSADO 

Double button press event. Generated when two buttons are pressed simultaneously.

ev_ENABLE_BUTTON_REBOUNCE_ALARM 

Button debounce alarm event. Enables button anti-bounce protection.

ev_TEST_CS_MAIN 

Counter Strike test event. Used for game testing procedures.

ev_DUMP_ALL_STATS 

Statistics dump event. Generates a complete system status report.

ev_UART_FREED 

UART available event. Indicates UART is free and ready for use.
